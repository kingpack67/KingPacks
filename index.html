Как добавить свои ресурс-паки?
1. Положи ZIP-файл пака в папку packs.
2. Открой файл index.html в редакторе и найди массив const packs внизу страницы.
3. Добавь туда карточку: название, описание, версию и путь к ZIP-файлу. Для превью можно указать ссылку на картинку в поле image.
4. Загрузи обновлённую папку сайта на GitHub Pages. Не распаковывай сам ресурс-пак — посетители скачивают ZIP.
